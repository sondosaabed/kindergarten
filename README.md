# نظام إدارة الروضة — دليل التشغيل والتطوير

## 🗂️ هيكلة المشروع (وحدات مستقلة)
تم تقسيم التطبيق بحيث يمكنك تطوير كل شاشة بشكل منفصل دون التأثير على البقية:

```
app.py              → نقطة التشغيل فقط (إعداد الصفحة + تسجيل الدخول + التوجيه بين الشاشات)
sidebar.py           → القائمة الجانبية (الشعار، الإحصائيات السريعة، أزرار التنقل)
auth.py               → شاشة تسجيل الدخول
ui.py                  → عناصر مشتركة (بطاقات، عناوين الأقسام، الشعار...)
receipt.py            → وصل الدفع القابل للطباعة بضغطة واحدة
style.py               → التنسيق العام (الألوان، الاستجابة للجوال)
db.py / helpers.py     → قاعدة البيانات والمنطق المشترك (لا تُعدَّل عادة)

sections/
    dashboard.py        → لوحة التحكم
    students.py          → الطلاب
    parents.py            → أولياء الأمور
    teachers.py            → المعلمون
    classes.py              → الصفوف
    academic_years.py        → السنوات الدراسية
    registration.py           → التسجيل
    payments.py                → الدفعات المالية
    reports.py                  → التقارير
```

**لتطوير شاشة واحدة فقط:** افتح ملفها داخل `sections/` وعدّل عليها مباشرة — كل شاشة تحتوي دالة واحدة `render(conn)` ولا تعتمد على غيرها. مثالي لخطة "شاشة واحدة يومياً".

⚠️ **لا تُسمِّ المجلد `pages`** — هذا اسم محجوز في Streamlit يُفعِّل قائمة تنقل تلقائية مختلفة عن قائمتنا المخصصة في `sidebar.py`. استخدم `sections/` كما هو.

## 🧭 القائمة الجانبية الجديدة
تم استبدال أزرار الراديو بقائمة أزرار عصرية: الشاشة الحالية تظهر بلون العلامة التجارية (أخضر/أبيض) وباقي الشاشات شفافة. الشعار الآن بحجم ثابت ومتناسق في كل مكان (القائمة الجانبية وشاشة الدخول).

## 🖨️ طباعة الوصل بضغطة واحدة
بعد حفظ أي دفعة، يظهر الوصل داخل صندوق خاص به زر **"🖨️ طباعة الوصل"** يفتح نافذة الطباعة مباشرة لمحتوى الوصل فقط — لا حاجة لاستخدام Ctrl/Cmd+P أو طباعة الصفحة كاملة.

## 🔐 تسجيل الدخول (مهم قبل النشر)
**محلياً (على جهازك):**
1. أنشئ مجلد `.streamlit` بجانب `app.py` إن لم يكن موجوداً
2. انسخ `.streamlit/secrets.toml.example` إلى `.streamlit/secrets.toml`
3. عدّل اسم المستخدم وكلمة المرور:
   ```toml
   [auth]
   username = "manager"
   password = "اختر-كلمة-مرور-قوية"
   ```
4. **لا ترفع ملف `secrets.toml` نفسه إلى GitHub.**

**على Streamlit Community Cloud (بعد النشر):**
1. من لوحة التطبيق: **Settings → Secrets**
2. الصق نفس المحتوى أعلاه واحفظ.

## 📱 الاستخدام من الجوال
الأعمدة تتحول لعمود واحد، الأزرار والحقول تكبر لتناسب اللمس، والقائمة الجانبية تُفتح عبر أيقونة ☰. لا حاجة لأي إعداد إضافي.

## التشغيل
1. Python 3.9+
2. ```
   pip install -r requirements.txt
   ```
3. تأكد من وجود كل الملفات والمجلدات التالية بجانب بعضها: `app.py`, `db.py`, `helpers.py`, `style.py`, `auth.py`, `ui.py`, `sidebar.py`, `receipt.py`, مجلد `sections/`, `school_data.db`, مجلد `assets/` (فيه `logo.png`)، ومجلد `.streamlit` (فيه `secrets.toml`)
4. ```
   streamlit run app.py
   ```

## ملاحظات

- **الترتيب المقترح عند أول استخدام:** المعلمون ← الصفوف ← السنة الدراسية ← أولياء الأمور ← الطلاب ← التسجيل ← الدفعات المالية.
