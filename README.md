# نظام إدارة الروضة — دليل التشغيل السريع

## التشغيل
1. تأكد من تثبيت Python 3.9+
2. ثبّت المتطلبات:
   ```
   pip install -r requirements.txt
   ```
3. ضع الملفات التالية في نفس المجلد: `app.py`, `db.py`, `helpers.py`, `style.py`, `school_data.db`
4. شغّل التطبيق:
 & C:\Users\hp\AppData\Local\Programs\Python\Python313\python.exe -m streamlit run c:/Users/hp/Desktop/files/app.py 
   ```
   streamlit run app.py
   ```

## ملاحظات
- قاعدة البيانات المرفقة `school_data.db` تحتوي بيانات التجربة السابقة وتُحدَّث تلقائياً بالجداول الجديدة عند أول تشغيل — لا حاجة لأي إعداد يدوي.
- **الترتيب المقترح عند أول استخدام:** المعلمون ← الصفوف ← السنة الدراسية ← أولياء الأمور ← الطلاب ← التسجيل ← الدفعات المالية، لأن كل خطوة تعتمد على سابقتها.
- حالة التسجيل (مسجل جديد / منتظم) تتحدث تلقائياً بمجرد تسجيل دفعة "رسوم تسجيل" — لا حاجة لتعديلها يدوياً.
- زر تحميل Excel متاح في كل شاشة تقارير.
- لطباعة وصل الدفع: بعد حفظ الدفعة، استخدم أمر الطباعة في المتصفح (Ctrl/Cmd + P).
