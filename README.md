# نظام إدارة الروضة — دليل التشغيل السريع

## 🔐 تسجيل الدخول (مهم قبل النشر)
التطبيق الآن محمي بشاشة دخول، لذا لن يستطيع أي شخص فتح الرابط والتعديل مباشرة.

**محلياً (على جهازك):**
1. أنشئ مجلد `.streamlit` بجانب `app.py` إن لم يكن موجوداً
2. انسخ `.streamlit/secrets.toml.example` إلى `.streamlit/secrets.toml`
3. عدّل اسم المستخدم وكلمة المرور داخل الملف:
   ```toml
   [auth]
   username = "manager"
   password = "اختر-كلمة-مرور-قوية"
   ```
4. **لا ترفع ملف `secrets.toml` نفسه إلى GitHub** — ملف `.example` فقط هو المخصص للمشاركة.

**على Streamlit Community Cloud (بعد النشر):**
1. من لوحة التطبيق اذهب إلى **Settings → Secrets**
2. الصق نفس المحتوى:
   ```toml
   [auth]
   username = "manager"
   password = "اختر-كلمة-مرور-قوية"
   ```
3. احفظ — سيُعاد تشغيل التطبيق تلقائياً وستظهر شاشة الدخول لأي زائر.

يمكن تغيير كلمة المرور في أي وقت من نفس الشاشة على Cloud دون تعديل الكود.

## 📱 الاستخدام من الجوال
التطبيق متجاوب مع شاشات الجوال تلقائياً: الأعمدة تتحول لعمود واحد، الأزرار والحقول تكبر لتناسب اللمس، والقائمة الجانبية تُفتح عبر أيقونة ☰ أعلى الشاشة. لا حاجة لأي إعداد إضافي — يعمل من نفس الرابط على الهاتف مباشرة.


## التشغيل
1. تأكد من تثبيت Python 3.9+
2. ثبّت المتطلبات:
   ```
   pip install -r requirements.txt
   ```
3. ضع الملفات والمجلدات التالية بجانب بعضها: `app.py`, `db.py`, `helpers.py`, `style.py`, `auth.py`, `school_data.db`, مجلد `assets/` (يحتوي `logo.png`)، ومجلد `.streamlit` بداخله `secrets.toml`
4. شغّل التطبيق:
   ```
   streamlit run app.py
   ```

## ملاحظات
- قاعدة البيانات المرفقة `school_data.db` تحتوي بيانات التجربة السابقة وتُحدَّث تلقائياً بالجداول الجديدة عند أول تشغيل — لا حاجة لأي إعداد يدوي.
- **الترتيب المقترح عند أول استخدام:** المعلمون ← الصفوف ← السنة الدراسية ← أولياء الأمور ← الطلاب ← التسجيل ← الدفعات المالية، لأن كل خطوة تعتمد على سابقتها.
- حالة التسجيل (مسجل جديد / منتظم) تتحدث تلقائياً بمجرد تسجيل دفعة "رسوم تسجيل" — لا حاجة لتعديلها يدوياً.
- زر تحميل Excel متاح في كل شاشة تقارير.
- لطباعة وصل الدفع: بعد حفظ الدفعة، استخدم أمر الطباعة في المتصفح (Ctrl/Cmd + P).
